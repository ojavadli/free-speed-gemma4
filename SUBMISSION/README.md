# What to do on Kaggle

The Kaggle CLI is not installed here, so the notebook was not pushed. The git repo is already public.

1. Open https://www.kaggle.com/competitions/gemma-4-developer-agent-paper and click Join Hackathon. Do this on both accounts (Anni Zimina and Orkhan Javadli), then merge into one team.
2. Open Writeups, then New Writeup. Paste `TITLE.txt` into the title, `SUBTITLE.txt` into the subtitle, and `BODY.md` into the body. Upload `cover.png`, `fig_speedup.png`, and `fig_by_kind.png`. Under Project Links add https://github.com/ojavadli/free-speed-gemma4 and, after you upload it, the Kaggle notebook URL.
3. To publish the notebook: on Kaggle, New Notebook, upload `notebook/free_speed_reproduce.ipynb` from the repo, set it public, attach this competition, no GPU, no internet. Then click Submit on the Writeup and confirm the page says Submitted.

Do step 3 before 14:30 Pacific. The contest closes at 15:59 Pacific.
